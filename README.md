# tg-assistance-bot

Telegram-бот на [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI): принимает фотографию в чате и после подтверждения публикует её в сторис подключённого бизнес-аккаунта.

Состояние ожидающих публикации фотографий хранится в памяти процесса.

## Как это работает

1. Пользователь пишет `/start` или нажимает кнопку «Старт».
2. Бот показывает статусы соцсетей и кнопки входа/выхода с названием платформы.
3. Пользователь присылает фотографию.
4. Бот предлагает отметить соцсети, добавить текст или отменить.
5. После добавления текста бот показывает превью фотографии с подписью.
6. Под превью можно опубликовать историю, изменить текст или отменить публикацию.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` или кнопка «Старт» | меню подключений соцсетей |
| `/status` | текущие подключения |
| `/login` | подключить аккаунт Telegram заново |
| `/logout` | удалить сессию Telegram |
| `/vk_login` | подключить VK |
| `/vk_logout` | отключить VK |
| `/vk_status` | статус VK |

Бот отвечает только в личных чатах.

## Переменные окружения

Задаёт тот, кто деплоит сервис, в `.env` на хосте. Пользователи бота их не вводят.

| Переменная | Назначение |
|------------|------------|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather). |
| `BUSINESS_CONNECTION_ID` | идентификатор подключения Telegram Business для публикации сторис. |
| `VK_APP_ID` / `VK_CLIENT_SECRET` | приложение VK ID для OAuth. |
| `VK_PUBLIC_BASE` или `DOMAIN` | публичный HTTPS-базовый URL бота (Bothost задаёт `DOMAIN`). Redirect: `{base}/vk/callback`. |
| `VK_REDIRECT_URI` | полный redirect URI, если нужен путь не `/vk/callback`. |
| `PORT` | порт HTTP (Bothost, обычно `3000`); должен совпадать с портом в панели. |

Trusted redirect URI в кабинете VK ID должен совпадать с `VK_REDIRECT_URI` / `{DOMAIN}/vk/callback`.

Файл `.env` подхватывается через `python-dotenv`.

## Установка и запуск

Нужен Python 3.9+.

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Процесс должен работать постоянно (long polling).

## Структура репозитория

- `main.py` — точка входа, polling.
- `controller/` — команды, логин в чате, фото, кнопки Да/Нет.
- `model/` — состояние пользователей в памяти и Telethon (логин и публикация сторис).
- `view/` — тексты и клавиатуры.

Версия приложения задаётся в `version.py`.
