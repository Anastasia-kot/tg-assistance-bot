# tg-assistance-bot

Telegram-бот на [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI): принимает фотографию в чате и после подтверждения публикует её в сторис подключённого бизнес-аккаунта.

Состояние ожидающих публикации фотографий хранится в памяти процесса.

## Как это работает

1. Пользователь пишет `/start`.
2. Пользователь присылает фотографию.
3. Бот спрашивает «Опубликовать в сторис Telegram?» с кнопками **Да** / **Нет**.
4. **Да** — фотография публикуется в сторис бизнес-аккаунта. **Нет** — публикация отменяется.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | приветствие; если аккаунт не подключён — запрос номера |
| `/login` | подключить аккаунт заново |
| `/status` | подключен ли аккаунт (без секретов) |
| `/logout` | удалить сессию |

Бот отвечает только в личных чатах.

## Переменные окружения

Задаёт тот, кто деплоит сервис, в `.env` на хосте. Пользователи бота их не вводят.

| Переменная | Назначение |
|------------|------------|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather). Единственный секрет для запуска. |
| `BUSINESS_CONNECTION_ID` | идентификатор подключения Telegram Business для публикации сторис. |

Файл `.env` подхватывается через `python-dotenv`.

## Установка и запуск

Нужен Python 3.9+.

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Процесс должен работать постоянно (long polling).

## Структура репозитория

- `main.py` — точка входа, polling.
- `controller/` — команды, логин в чате, фото, кнопки Да/Нет.
- `model/` — состояние пользователей в памяти и Telethon (логин и публикация сторис).
- `view/` — тексты и клавиатуры.

Версия приложения задаётся в `version.py`.
