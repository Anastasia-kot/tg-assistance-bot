# tg-assistance-bot

Telegram-бот принимает фотографию и публикует её в Stories Telegram, MAX или
обеих платформ. Telegram использует официальный Business Bot API, MAX —
неофициальные API через `maxion` и `PyMax`.

Состояние ожидающих публикации фотографий хранится в памяти процесса. Сессии
MAX сохраняются отдельно для каждого Telegram-пользователя в JSON-файлах.

## Как это работает

1. Пользователь пишет `/start`.
2. Для MAX пользователь запускает `/max_login`, подтверждает риски и входит
   по QR из приложения MAX. QR создаёт Android-сессию, не web. Вход по SMS
   оставлен как резерв.
3. Пользователь присылает фотографию.
4. Бот предлагает выбрать Telegram, MAX, обе платформы, добавить текст или отменить.
5. После добавления текста бот показывает превью фотографии с подписью.
6. Под превью можно выбрать платформу, изменить или убрать текст либо отменить публикацию.

Текстовые слои MAX пока не публикуются: их формат во внутреннем API не
подтверждён. Фото с текстом можно отправить в Telegram; для MAX нужно убрать
текст. При частичном успехе повтор не дублирует уже опубликованную историю.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | начать работу |
| `/status` | проверить настройку Telegram Stories |
| `/max_login` | подключить личный MAX-аккаунт |
| `/max_status` | проверить MAX-сессию |
| `/max_logout` | завершить и удалить MAX-сессию |

Бот отвечает только в личных чатах.

## Переменные окружения

Задаёт тот, кто деплоит сервис, в `.env` на хосте. Пользователи бота их не вводят.

| Переменная | Назначение |
|------------|------------|
| `BOT_TOKEN` | токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `BUSINESS_CONNECTION_ID` | идентификатор подключения Telegram Business для публикации сторис. |
| `MAX_SESSION_DIR` | каталог JSON-сессий MAX; по умолчанию `.sessions/max` |

Файл `.env` подхватывается через `python-dotenv`.

## Установка и запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Процесс должен работать постоянно (long polling).

## Риски MAX

Перед входом бот показывает предупреждение и требует явного подтверждения.
Рекомендуемый вход по QR не требует передавать боту номер, одноразовый код или
пароль. Вход по SMS оставлен как резервный способ; код и пароль удаляются из
чата после обработки. Сессионный токен MAX хранится в JSON-файле с правами
`0600`, не добавляется в Git и удаляется по `/max_logout`.

MAX API неофициальный: протокол может измениться, сессия может быть отозвана,
а аккаунт — ограничен. Подключать следует только собственный аккаунт.

## Структура репозитория

- `main.py` — точка входа, polling.
- `controller/` — команды, MAX-авторизация, фото и callback-кнопки.
- `model/` — pending-состояние, MAX-сессии и публикация Stories.
- `view/` — тексты и клавиатуры.

Версия приложения задаётся в `version.py`.
